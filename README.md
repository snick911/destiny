# destiny

八字紫微排盤程式：子平八字（四柱）與紫微斗數兩種排盤，使用 Java Swing 打造，
內建護眼暗色主題。畫面上方的「八字／紫微斗數」按鈕（或 Ctrl+1／Ctrl+2）切換
兩種排盤，出生資料共用同一組輸入。

輸入西元出生年、月、日、時（下拉選單 0~23 時，並附對應時辰地支；
可選填分鐘）與性別，程式會依「立春」判定
流年、以十二節劃分月柱、以儒略日數推算日柱、並依五鼠遁推算時柱，顯示
年柱、月柱、日柱、時柱的天干地支、五行，以及以日主（日干）為基準推算
的十神（含年干/月干/時干十神，與各柱地支藏干十神）；並依性別與年干
陰陽推算大運（順排／逆排、起運歲數與各期干支、十神、藏干）。

**紫微斗數**則將出生時刻換算為農曆（以天文計算推得），排出十二宮命盤：
命宮、身宮、宮干、五行局、十四主星、六吉星、六煞星、祿存天馬與二十個雜曜，
標示生年四化、命主身主與十二步大限；並可疊上所選大限、流年、流月的宮位、
四化與祿羊陀馬魁鉞（流年另有流昌流曲、紅鸞天喜），以斗君標示各宮流月、
以及當年小限。安星規則參考 lifeup 專案並修正其中的錯誤（見下方「紫微斗數
排盤規則」）。

目前版本：**1.2.1**（各版本變更見 [CHANGELOG.md](CHANGELOG.md)）。

## 下載與執行（一般使用者）

到 GitHub 的 [Releases](https://github.com/snick911/destiny/releases) 頁面下載：

- **Windows 免安裝版**（建議，**不需安裝 Java**）：
  `destiny-bazi-<版本>-windows-x64.zip`，解壓縮後雙擊 `DestinyBazi\DestinyBazi.exe`。
  程式未經數位簽章，第一次執行若出現 Windows SmartScreen 警告，請按
  「其他資訊」→「仍要執行」。
- **跨平台版**（需已安裝 Java 17 以上）：`destiny-bazi-<版本>.zip`，解壓縮後
  Windows 雙擊 `run-windows.bat`；macOS / Linux 執行 `./run-mac-linux.sh`，
  或直接 `java -jar destiny-bazi.jar`。Linux 需已安裝中文字型（例如
  `fonts-noto-cjk` 或 `fonts-wqy-zenhei`），否則中文會顯示為方框。

## 執行（直接使用已建置的 JAR）

`dist/destiny-bazi.jar` 是以 `--release 17` 編譯、可獨立執行的 JAR
（位元組碼版本 61＝Java 17；純 JDK，不依賴任何第三方套件），只需
JRE/JDK 17 以上即可直接執行：

```bash
java -jar dist/destiny-bazi.jar
```

## 從原始碼編譯與執行

需要 JDK 17 以上。

```bash
# 編譯（以 Java 17 語言／位元組碼相容性編譯）
javac --release 17 -d out -encoding UTF-8 $(find src/main/java -name "*.java")

# 執行
java -cp out com.destiny.bazi.Main
```

## 測試

```bash
./build.sh
```

`build.sh` 會先編譯並執行 `src/test/java` 的自動測試，**任何一項失敗即停止
打包**。測試不依賴第三方套件，涵蓋：節氣時刻（與 26 筆官方公布時刻比對、
1900~2100 年順序與間隔）、四柱（公開八字、立春交界、子時換日、五虎遁／
五鼠遁）、十神與藏干表、流年流月、大運（順逆、起運、交運日期與各期年份）、
五行質量與十神統計、以傳統口訣查表的獨立實作交叉比對一萬個隨機命盤、
農曆換算（1900~2100 年逐日與香港天文台曆表比對）、紫微斗數（逐宮核對範例
命盤、紫微星諸局表、閏月與晚子時、大限流年流月斗君小限，並以依口訣字串
另行撰寫的獨立實作交叉比對兩萬個隨機命盤的命身宮、五行局、48 顆星曜、四化
與大限）、存檔與載入，以及介面冒煙測試（開啟主視窗、切換所有大運／流年／
流月、切換紫微斗數的所有大限／流年／流月與點選宮位、字體縮放、繪製匯出圖片）
與自我檢測。介面測試需要顯示環境；沒有顯示環境時
若有 `xvfb-run` 會自動使用，否則略過。

打包後的程式也可自我檢測：`DestinyBazi.exe --self-test 報告.txt`（或
`java -jar destiny-bazi.jar --self-test 報告.txt`）會開啟主視窗、排已知的八字與
紫微斗數命盤並寫出報告（作業系統、Java 版本、選用字型、排盤結果），正常時結束碼為
0、報告最後一行為 `result=OK`。GitHub Actions 以此驗證 Windows 免安裝版。

也可只執行測試：

```bash
javac --release 17 -encoding UTF-8 -d out $(find src/main/java -name "*.java")
javac --release 17 -encoding UTF-8 -cp out -d out-test $(find src/test/java -name "*.java")
java -cp out:out-test com.destiny.bazi.tests.AllTests
```

## 打包與發佈新版本

```bash
./build.sh
```

`build.sh` 會在測試通過後重新編譯並產生 `dist/destiny-bazi.jar`（manifest 內含
`Implementation-Version`）與 `dist/destiny-bazi-<版本>.zip`（JAR、啟動檔、
README、CHANGELOG）。發佈新版本的步驟：

1. 修改 `src/main/java/com/destiny/bazi/AppInfo.java` 的 `VERSION`
2. 在 `CHANGELOG.md` 新增該版本的變更紀錄
3. 執行 `./build.sh`，提交 `dist/` 下的新檔案
4. 合併到 `main`：GitHub Actions（`.github/workflows/release.yml`）會自動
   執行測試、建置跨平台 zip 與 Windows 免安裝版（並在 Windows 上執行
   `DestinyBazi.exe --self-test` 驗證），全部成功後建立 `v<版本>` 標籤與 Release 並附上
   兩個 zip；版本號已發佈過則略過，不會覆蓋

Windows 免安裝版由 `jpackage` 在 Windows 上產生（內含只保留 `java.desktop`
模組的精簡 Java 執行環境），因此只在 GitHub Actions 的 Windows 主機上建置；
對 `main` 開的 PR 也會先跑一次建置，確認可以打包。

畫面文字一律使用繁體中文，並會優先選用系統上可用的繁體中文字型
（依序嘗試 Microsoft JhengHei、PingFang TC、Heiti TC、Noto Sans TC 等，
找不到則退回系統無襯線字型）。

## 排盤規則說明

- **年柱**：以「立春」時刻為界，而非西曆 1 月 1 日或農曆春節。
- **月柱**：以十二個「節」（立春、驚蟄、清明…）劃分月支交界，
  月支固定為寅卯辰巳午未申酉戌亥子丑；月干依年干以「五虎遁」推算。
- **日柱**：以儒略日數（Julian Day Number）對 60 取餘推算干支，
  並依「晚子時」慣例，23:00~23:59 出生者日柱順延至次日推算。
- **時柱**：時支依出生時刻對應十二時辰，時干依日干以「五鼠遁」推算。
- **十神**：以日干（日主）為基準，依五行生克與陰陽同異，判定其餘三柱
  天干及四柱地支藏干（本氣／中氣／餘氣）的十神——比肩、劫財、食神、
  傷官、偏財、正財、七殺（偏官）、正官、偏印、正印。
- **月令**：出生時刻在月柱地支中實際「當令」的天干與五行。辰戌丑未
  （四墓庫月）依入節天數分三階段——前 5 天為上個節氣殘留的餘氣當令
  （辰乙木／未丁火／戌辛金／丑癸水，即前一地支本氣），中間 9 天為
  該支所藏墓庫之氣（中氣）當令（辰癸水／未乙木／戌丁火／丑辛金），
  之後（第 15~30 天）才是純粹的本氣（戊／己土）當令；其餘地支不分
  階段，直接以該支本氣為月令。
- **五行質量**：先以原始命盤算出五行基本分——四柱天干權重 1，地支藏干
  依藏干數分配權重（單藏 1；雙藏 2/3、1/3；三藏 2/4、1/4、1/4），總和
  為木火土金水各自的基本分；再以月令五行為「我」，依旺相休囚死為每個
  五行各加一次月令加分——當我者旺（+2）、我生者相（+1.5）、生我者休
  （+1）、剋我者囚（+0.5）、我剋者死（+0）；基本分加上月令加分即為
  五行總分（五者之和固定為 13：基本分總和 8 加上月令加分總和 5）。選定
  大運與流年後，另計算一組「命盤＋大運＋流年」五行質量——以相同方式
  將所選大運柱、流年柱的天干與地支藏干併入基本分（月令加分仍以命盤
  月令為準），五者之和固定為 17（基本分總和 12 加上月令加分總和 5），
  顯示於大運／流年／流月查詢區塊，隨大運或流年切換即時更新。兩組五行
  質量皆以水平長條圖呈現，長條寬度依各五行佔總分的比例繪製，並標示
  數值與百分比；長條圖旁另附十神統計，計算範圍與對應的五行質量一致
  （命盤四柱天干〔日主本身不計〕與地支藏干的十神次數，或再加上所選
  大運柱、流年柱），非零項以強調色標示。
- **大運**：依「陽男陰女順排、陰男陽女逆排」判定方向（陽／陰依年干），
  以出生時刻與最近節氣的距離換算起運歲數（三日折一歲、一日折四個月），
  再從月柱起、依方向逐期推算八期大運（每期十年）的干支、十神與地支藏干。
  出生日期加上起運的歲、月、天即為**交運日期**；第一期大運自交運當年
  起算，其後每期十年，每張大運卡片標示起訖年份與歲數（歲數＝年份－
  出生年，即當年滿幾歲，與流年清單一致）。
- **流年**：選定某一期大運後，可從該期涵蓋的十個西元年份（交運當年起
  連續十年）中選擇特定一年，直接以該年份推算年柱干支、十神與地支藏干。
- **流月**：選定流年後，可從該年正月~十二月中選擇特定一月；月支固定
  順序為寅卯辰巳午未申酉戌亥子丑，月干依該流年年干以「五虎遁」推算，
  同樣附十神與地支藏干。
- 節氣時刻採 VSOP87 地球黃經截斷級數（Meeus《Astronomical Algorithms》
  附錄係數）計算太陽視黃經（含 FK5 修正、章動、光行差），並以 ΔT 換算地球時
  與世界時，搭配牛頓法疊代精確求解每 15° 交角時刻；與香港天文台公布的節氣
  時刻比對誤差約在 1 分鐘以內（舊版低精度公式誤差可達 8 分鐘，交節前後出生者
  可能排錯月柱／年柱）。已與外部命理網站（myfate.herokuapp.com）測試比對，四柱／十神／
  藏干／大運方向與干支序列完全一致，起運天數誤差通常在 1 天以內。
- 所有輸入時間預設視為當地（北京時間 UTC+8）出生時刻。
- 每張柱卡（年柱／月柱／日柱／時柱／各期大運）的天干與地支字元一律
  上緣對齊，不因地支藏干行數（1~3 行）不同而錯位。

## 紫微斗數排盤規則

- **農曆換算**：依 GB/T 33661-2017《農曆的編算和頒行》以天文計算推得——
  北京時間合朔所在日為初一，含冬至的月為十一月，兩個十一月之間有十三個月時，
  第一個不含中氣的月為閏月。朔的時刻採 Meeus《Astronomical Algorithms》第 49 章，
  中氣沿用八字的節氣計算。民國初年（1912~1928 年）曆書以北京地方平時編算，
  這段期間同樣改以地方平時判定日期；2057、2089、2097 年各有一個朔距午夜不到
  3 分鐘，超出推算精度，依香港天文台曆表歸入次日。1900~2100 年逐日換算結果
  與香港天文台曆表完全一致。
- **年、月、日、時**：年以正月初一為界（八字則以立春為界）；23 時屬晚子時，
  以次日的農曆日排盤（與八字的日柱換日一致）；**閏月十五日以前屬本月，
  十六日起屬下個月**。
- **命宮、身宮**：寅宮起正月，順數至生月，再由該宮起子時逆數至生時為命宮、
  順數至生時為身宮。十二宮自命宮起逆排：命宮、兄弟、夫妻、子女、財帛、疾厄、
  遷移、交友、事業、田宅、福德、父母。宮干依年干以五虎遁起寅宮。
- **五行局**：命宮干支的納音五行——水二局、木三局、金四局、土五局、火六局。
- **紫微星**：生日加上借數使其能被局數整除，商數自寅宮起數；借數為偶數則
  再順進、為奇數則逆退。紫微系逆行：紫微、天機（－1）、太陽（－3）、武曲（－4）、
  天同（－5）、廉貞（－8）；天府與紫微以寅申為軸對稱，天府系順行：天府、太陰、
  貪狼、巨門、天相、天梁、七殺、破軍（＋10）。
- **輔佐煞曜**：左輔辰宮起正月順、右弼戌宮起正月逆；文昌戌宮起子時逆、文曲
  辰宮起子時順；祿存依年干（甲寅乙卯丙戊巳丁己午庚申辛酉壬亥癸子），擎羊在前、
  陀羅在後；天魁天鉞「甲戊庚牛羊、乙己鼠猴鄉、丙丁豬雞位、壬癸兔蛇藏、六辛逢
  馬虎」；天馬依年支三合（寅午戌在申…）；火星鈴星依年支起、順數至生時；
  地劫地空亥宮起子時，劫順空逆。
- **雜曜**：天刑、天姚、陰煞、天巫、解神依生月；紅鸞（卯宮起子逆數至年支）、
  天喜（紅鸞對宮）、咸池、華蓋、孤辰、寡宿、破碎、天哭、天虛依年支；天官、
  天福依年干；台輔（午宮起子時順）、封誥（寅宮起子時順）依生時；天才自命宮、
  天壽自身宮起子順數至年支。
- **四化**：甲廉破武陽、乙機梁紫陰、丙同機昌廉、丁陰同機巨、戊貪陰右機、
  己武貪梁曲、庚陽武陰同、辛巨陽曲昌、壬梁紫左武、癸破巨陰貪。
- **命主、身主**：命主依命宮地支（子貪狼、丑亥巨門、寅戌祿存…），身主依年支
  （子午火星、丑未天相、寅申天梁…）。
- **大限**：自命宮起，第一限起於五行局數之歲（虛歲），陽男陰女順行、陰男陽女
  逆行，每宮十年；大限四化依大限命宮的宮干，並排大祿、大羊、大陀、大馬、大魁、大鉞。
- **流年**：流年命宮在該年地支宮，依年干四化，並排流祿、流羊、流陀、流馬、
  流魁、流鉞、流昌、流曲、流鸞、流喜。**斗君**：自流年地支宮起正月逆數至生月，
  再起子時順數至生時，即流年正月所在宮，其後各月依序順行。**小限**依年支三合
  起一歲（寅午戌辰、申子辰戌、巳酉丑未、亥卯未丑），男順女逆。
- **流月**：流月命宮在斗君起算的該月宮位，月干依流年年干以五虎遁推算，依月干
  四化並排月祿、月羊、月陀、月馬、月魁、月鉞。
- **與 lifeup 的差異（修正）**：紫微在寅或申時天府與紫微同宮（lifeup 誤排到
  對宮）；庚年天魁天鉞在丑未（lifeup 漏排）；巳年的火星鈴星照巳酉丑起排（lifeup 把巳誤寫為辰，
  巳年漏排）；天哭天虛依生年地支（lifeup 誤用生時）；封誥自寅宮起子時順數
  （lifeup 為逆數，與「台輔、封誥夾文曲」不符）。另外兩項慣例與 lifeup 不同：
  閏月出生者 lifeup 一律以本月排盤，本程式十五日以前屬本月、十六日起屬下個月；
  23 時出生者 lifeup 不換日，本程式與八字一致以次日排盤。lifeup 的「好運指數」
  評分未移植。

### 紫微斗數畫面

命盤以傳統四方格排列（巳午未申在上、寅丑子亥在下），中央兩格顯示姓名、陽曆、
農曆、陰陽男女、五行局、命身宮、命主身主、生年四化，以及所選大限／流年／流月
與其四化。每宮以直書由右至左列出星曜（主星白色粗體、六吉綠、六煞紅、祿馬金、
雜曜灰），星名下方的小方塊為四化：實心為生年四化，外框為大限（橙）、流年
（青綠）、流月（粉紅）四化。宮位底部依序為大限歲數、斗君流月與小限、宮干支、
宮名（命宮以強調色、身宮加「身」標記），以及疊上的大限／流年／流月宮名
（如「大命」「流財」「月父」）；行運星曜（如「大祿」「流羊」）列在其上。
大限、流年、流月的命宮分別以該層顏色的外框標示。

「盤面」選單決定疊到哪一層（本命盤／大限盤／流年盤／流月盤）；選擇大限、
流年或流月時盤面會自動疊到該層。排盤後預設選到今天所在的大限、流年與流月
（以農曆為準）；第一限的流年清單另含起限前的童限年份。**點選任一宮位即切換到
該宮的大限**。字體放大而視窗不夠寬時，命盤會自動縮小以完整顯示；匯出圖片則
以所選字級完整繪製。

## 姓名與人員資料

輸入區第一列可填寫**姓名**（選填），填寫後命盤摘要會顯示姓名。

- **儲存人員**（Ctrl+D，或在姓名欄按 Enter）：以姓名為準，把目前的出生
  年月日時分與性別存入人員資料；已有同名人員且出生資料不同時，會先詢問
  是否覆蓋。
- **人員查詢…**（Ctrl+F）：開啟人員查詢小視窗，列出所有人員的姓名、出生
  時間、性別與八字。在搜尋框輸入姓名、日期（如 `1990-05`）或干支（如
  `庚午`）即時篩選，↑／↓ 移動選取，按 Enter、雙擊或「帶入」即把該人員
  資料填入主畫面並排盤；選取後按「刪除」（或 Delete 鍵）可刪除人員。

人員資料存放於使用者家目錄下的 `.destiny-bazi/people.tsv`（Windows 為
`C:\Users\<使用者>\.destiny-bazi\people.tsv`），為 UTF-8 純文字檔、每行
一人（姓名、年、月、日、時、分、性別以 Tab 分隔），可自行備份或複製到
其他電腦使用。

## 選單功能

- **檔案 → 儲存人員**（Ctrl+D）／**人員查詢...**（Ctrl+F）：見上方「姓名與人員資料」。
- **檔案 → 儲存結果...**（Ctrl+S）：將目前輸入的姓名、出生年月日時分、性別與
  排盤結果存成 `.bazi` 純文字檔（UTF-8）。
- **檔案 → 載入結果...**（Ctrl+O）：讀取 `.bazi` 檔，還原出生年月日時分、
  性別並依目前排盤邏輯重新計算（確保結果與程式版本一致；舊檔案若無
  性別欄位則預設為男）。
- **檔案 → 匯出圖片...**（Ctrl+E）：將排盤輸入與目前模式的內容（八字：四柱、
  命盤摘要、大運、大運／流年／流月查詢；紫微斗數：十二宮命盤），依實際完整
  大小（不受目前視窗大小或捲動位置影響）繪製成一張 PNG 圖片並存檔。
- **顯示 → 八字排盤 / 紫微斗數**（Ctrl+1 / Ctrl+2）：切換排盤模式。
- **顯示 → 放大字體 / 縮小字體**（Ctrl+= / Ctrl+-）：等比例調整標題、輸入
  欄位、四柱卡片與大運卡片文字大小；**重設字體大小**（Ctrl+0）恢復預設。
- **說明 → 關於**：顯示版本號與排盤規則簡介。

## 版面配置

標題下方為「八字／紫微斗數」切換按鈕；紫微斗數模式在排盤輸入下方只顯示
紫微斗數命盤區塊（見上方「紫微斗數畫面」）。八字模式的畫面由上而下分為五個
獨立的卡片區塊，各自加上標題以利區分：
**排盤輸入**（姓名與人員資料按鈕、年月日時分、性別、排盤按鈕）→ **四柱**（年柱／月柱／
日柱／時柱）→ **命盤摘要**（含命盤本身的月令與五行質量）→ **大運**
（八期大運，標示今天所在的「目前」大運；點選卡片即切換下方查詢）→ **大運／流年／流月查詢**（「選擇大運」
「選擇流年」「選擇流月」三個下拉選單，選定後即時顯示該期大運、該年
流年、該月流月的干支、十神、地支藏干，以及「命盤＋大運＋流年」五行
質量）。整體內容置於可垂直捲動的容器中，內容寬度跟隨視窗，縮小視窗時
不會裁切內容；大運卡片在視窗夠寬時平均分配寬度，太窄或字體放大時才改為
可橫向捲動。日柱（日主）卡片以強調色框標示。

輸入的年、月、日、時、分、性別任一欄位變動即自動重新排盤；「日」的上限
依年月自動設為該月天數（含閏年二月）。排盤後查詢區預設選到今天所在的
大運、流年（以立春為界）與流月（以節氣為界），並標示「目前／今年／本月」。

選擇大運（下拉選單或直接點選大運卡片）後，流年下拉選單會自動更新為該期大運涵蓋的十個年份；選擇
流年後，流月下拉選單會自動更新為該年正月~十二月。切換大運、流年或
流月皆會立即重新計算並更新對應卡片，不需再按「排盤」。
