# destiny

子平八字（四柱）排盤程式，使用 Java Swing 打造，內建護眼暗色主題。

輸入西元出生年、月、日、時（可選填分鐘）與性別，程式會依「立春」判定
流年、以十二節劃分月柱、以儒略日數推算日柱、並依五鼠遁推算時柱，顯示
年柱、月柱、日柱、時柱的天干地支、五行，以及以日主（日干）為基準推算
的十神（含年干/月干/時干十神，與各柱地支藏干十神）；並依性別與年干
陰陽推算大運（順排／逆排、起運歲數與各期干支、十神、藏干）。

## 編譯與執行

需要 JDK 17 以上（純 JDK，不依賴任何第三方套件；程式碼相容於 `--release 17`）。

```bash
# 編譯（以 Java 17 語言／位元組碼相容性編譯）
javac --release 17 -d out -encoding UTF-8 $(find src/main/java -name "*.java")

# 執行
java -cp out com.destiny.bazi.Main
```

畫面文字一律使用繁體中文，並會優先選用系統上可用的繁體中文字型
（依序嘗試 Microsoft JhengHei、PingFang TC、Heiti TC、Noto Sans TC 等，
找不到則退回系統無襯線字型）。

## 排盤規則說明

- **年柱**：以「立春」時刻為界，而非西曆 1 月 1 日或農曆春節。
- **月柱**：以十二個「節」（立春、驚蟄、清明…）劃分月支交界，
  月支固定為寅卯辰巳午未申酉戌亥子丑；月干依年干以「五虎遁」推算。
- **日柱**：以儒略日數（Julian Day Number）對 60 取餘推算干支，
  並依「晚子時」慣例，23:00~23:59 出生者日柱順延至次日推算。
- **時柱**：時支依出生時刻對應十二時辰，時干依日干以「五鼠遁」推算。
- **十神**：以日干（日主）為基準，依五行生克與陰陽同異，判定其餘三柱
  天干及四柱地支藏干（本氣／中氣／餘氣）的十神——比肩、劫財、食神、
  傷官、偏財、正財、七殺（偏官）、正官、偏印、正印。
- **月令**：出生時刻在月柱地支中實際「當令」的天干與五行。辰戌丑未
  （四墓庫月）依入節天數分三階段——前 5 天為上個節氣殘留的餘氣當令
  （辰乙木／未丁火／戌辛金／丑癸水，即前一地支本氣），中間 9 天為
  該支所藏墓庫之氣（中氣）當令（辰癸水／未乙木／戌丁火／丑辛金），
  之後（第 15~30 天）才是純粹的本氣（戊／己土）當令；其餘地支不分
  階段，直接以該支本氣為月令。
- **五行質量**：以月令五行為「我」，依旺相休囚死加權四柱天干（權重 1）
  與地支藏干（單藏 1；雙藏 2/3、1/3；三藏 2/4、1/4、1/4）的五行分量，
  合計出木火土金水五個總分——當我者旺（+2）、我生者相（+1.5）、生我者
  休（+1）、剋我者囚（+0.5）、我剋者死（+0）。
- **大運**：依「陽男陰女順排、陰男陽女逆排」判定方向（陽／陰依年干），
  以出生時刻與最近節氣的距離換算起運歲數（三日折一歲、一日折四個月），
  再從月柱起、依方向逐期推算八期大運（每期十年）的干支、十神與地支藏干。
- **流年**：選定某一期大運後，可從該期涵蓋的十個西元年份中選擇特定
  一年，直接以該年份推算年柱干支、十神與地支藏干。
- **流月**：選定流年後，可從該年正月~十二月中選擇特定一月；月支固定
  順序為寅卯辰巳午未申酉戌亥子丑，月干依該流年年干以「五虎遁」推算，
  同樣附十神與地支藏干。
- 節氣時刻採太陽視黃經公式（Meeus《Astronomical Algorithms》低精度太陽座標，
  精度約 0.01°）搭配牛頓法疊代精確求解每 15° 交角時刻，較單純的回歸年平均法
  更準確；已與外部命理網站（myfate.herokuapp.com）測試比對，四柱／十神／
  藏干／大運方向與干支序列完全一致，起運天數誤差通常在 1 天以內。
- 所有輸入時間預設視為當地（北京時間 UTC+8）出生時刻。
- 每張柱卡（年柱／月柱／日柱／時柱／各期大運）的天干與地支字元一律
  上緣對齊，不因地支藏干行數（1~3 行）不同而錯位。

## 選單功能

- **檔案 → 儲存結果...**（Ctrl+S）：將目前輸入的出生年月日時分、性別與
  排盤結果存成 `.bazi` 純文字檔（UTF-8）。
- **檔案 → 載入結果...**（Ctrl+O）：讀取 `.bazi` 檔，還原出生年月日時分、
  性別並依目前排盤邏輯重新計算（確保結果與程式版本一致；舊檔案若無
  性別欄位則預設為男）。
- **檔案 → 匯出圖片...**（Ctrl+E）：將排盤輸入、四柱、大運、大運／流年／
  流月查詢、命盤摘要整段內容，依實際完整高度（不受目前視窗大小或捲動
  位置影響）繪製成一張 PNG 圖片並存檔。
- **顯示 → 放大字體 / 縮小字體**（Ctrl+= / Ctrl+-）：等比例調整標題、輸入
  欄位、四柱卡片與大運卡片文字大小；**重設字體大小**（Ctrl+0）恢復預設。
- **說明 → 關於**：顯示排盤規則簡介。

## 版面配置

畫面由上而下分為五個獨立的卡片區塊，各自加上標題以利區分：
**排盤輸入**（年月日時分、性別、排盤按鈕）→ **四柱**（年柱／月柱／
日柱／時柱）→ **大運**（可橫向捲動的八期大運）→ **大運／流年／流月
查詢**（「選擇大運」「選擇流年」「選擇流月」三個下拉選單，選定後即時
顯示該期大運、該年流年、該月流月的干支、十神、地支藏干）→ **命盤
摘要**。整體內容置於可垂直捲動的容器中，縮小視窗時不會裁切內容。

選擇大運後，流年下拉選單會自動更新為該期大運涵蓋的十個年份；選擇
流年後，流月下拉選單會自動更新為該年正月~十二月。切換大運、流年或
流月皆會立即重新計算並更新對應卡片，不需再按「排盤」。

```
├── Main.java                 # 程式進入點
├── core/
│   ├── GanZhi.java            # 天干地支五行生肖資料表
│   ├── Pillar.java            # 單柱（干支）資料模型
│   ├── SolarTerm.java         # 二十四節氣時刻推算
│   ├── TenGod.java            # 十神判定
│   ├── HiddenStems.java       # 地支藏干表
│   ├── HiddenStemGod.java     # 單一藏干及其十神
│   ├── PillarTenGods.java     # 單柱十神資訊（天干＋地支藏干）
│   ├── MonthOrder.java        # 月令（當令天干、五行、階段、入節天數）
│   ├── FiveElementMass.java   # 五行質量（旺相休囚死加權後的木火土金水總分）
│   ├── Gender.java            # 性別（決定大運順逆排）
│   ├── DaYunPeriod.java       # 單期大運（干支、起訖歲數、十神）
│   ├── DaYunResult.java       # 大運排盤結果
│   ├── LiuNianYear.java       # 單一流年（年份、干支、十神）
│   ├── LiuYueMonth.java       # 單一流月（年份、月份、干支、十神）
│   ├── BaziCalculator.java    # 排盤核心邏輯
│   └── BaziResult.java        # 排盤結果
├── io/
│   ├── BirthInput.java         # 出生年月日時分性別資料
│   └── BaziFileIO.java         # 排盤結果儲存／載入
└── ui/
    ├── DarkTheme.java          # 護眼暗色主題配色（含選單樣式）
    ├── PillarPanel.java        # 單柱顯示卡片（支援緊湊模式與字體縮放）
    └── BaziFrame.java          # 主視窗（選單列、儲存載入、匯出圖片、字體縮放、大運）
```
